# Support

`agent-skills` is a private, solo-maintained project. It is not a product, is not distributed for
outside use, and has no support channel or response commitment.

- **No SLA.** There is no triage queue and no review commitment.
- **No outside support.** This repository is not open to people outside it.
- **Security issues** are handled per [SECURITY.md](./SECURITY.md).

## Internal bug reports

Open an issue with the smallest reproducer you can, the skill name, the agent host (Claude Code,
Cursor, etc.), and relevant configuration with secrets stripped.
