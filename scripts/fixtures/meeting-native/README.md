# Native transcript fixtures

Sanitised response shapes for Microsoft Graph (onlineMeetings, transcripts), the Google Meet
REST API v2 (spaces, conferenceRecords, transcripts, entries, participants), and the Zoom API v2
(users/me, meetings, recordings), as documented on 2026-09-23. Every identifier, name, and URL is a
placeholder. `scripts/test-meeting.py` replays them through an injected transport; nothing here
was captured from a real tenant.
